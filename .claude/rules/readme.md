# README

`README.md` is the guide to this project: what the site is for, its pages,
stack, folder layout, how to add content and the commands.

- **Read it first.** Check the README before starting work, so changes follow
  the structure and conventions it describes.
- **Keep it current.** Update it in the same change whenever something it
  describes changes:
  - pages added, removed or renamed;
  - content collections or their frontmatter fields;
  - folders and files that move;
  - the stack, commands or setup steps;
  - placeholders that get replaced with real content.
- **Keep it short.** Describe what a newcomer needs to find their way around,
  not every component. Link to a rule file instead of repeating it.
